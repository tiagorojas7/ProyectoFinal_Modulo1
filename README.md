# Proyecto Final - Módulo 1: Porfolio Personal-Tiago Rojas

Este repositorio contiene el trabajo final correspondiente al **Módulo 1 de la Diplomatura Full Stack, realizada en icaro**.
El objetivo principal de esta entrega es demostrar el dominio de las tecnologías aprendidas en el modulo 1 para la creación de interfaces responsivas, estructuradas y visualmente atractivas.

## Tematica del proyecto

El rubro que se eligio para demostrar las habilidades y conocimientos adquieridos fue la creacion de un **porfolio personal**, donde se cuenta brevemente un poco desde quien soy, hasta las herramientas que domino, educacion,experiencia. con diferentes botones CTA para facilitar el contacto.

## Tecnologías Utilizadas:

Para el desarrollo de este sitio web se utilizaron las siguientes tecnologias:

- **HTML**: Estructuración semántica del contenido.
- **CSS**: Estilos personalizados, layouts y diseño visual.
- **Bootstrap**: Framework para agilizar el diseño y garantizar la adaptabilidad.
- **Responsive Design**: Adaptación fluida a dispositivos móviles, tablets y computadoras.

## Características del Proyecto:

- **Maquetación Semántica**: Uso correcto de etiquetas HTML5 (`<header>`, `<nav>`, `<main>`, `<footer>`, etc.).
- **Diseño Adaptable (Responsive)**: Implementación del sistema de grillas de Bootstrap para una visualización óptima en pantallas de cualquier tamaño e implementacion de mediaqueries.
- **Componentes Bootstrap**: Uso de barras de navegación, botones, formularios y tarjetas propias del framework.
- **Personalización con CSS**: Ajustes específicos de estilos propios que complementan y extienden las clases de Bootstrap.

## Estructura del Repositorio

La organización de los archivos del proyecto sigue el siguiente orden estándar:

```text
├── html/           # Archivos y páginas secundarias del sitio
├── css/            # Hojas de estilo personalizadas (.css)
├── public/         # Recursos estáticos (Imágenes, iconos, logos)
└── README.md       # Documentación del proyecto
```
